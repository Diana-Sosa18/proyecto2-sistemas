# Proyecto 2 - Sistemas Web

## Fase 1: useState + useEffect + Backend Express

### Descripción
CRUD de destinos de viaje construido con React en el frontend y Express + PostgreSQL en el backend.

### Mis primeros Items
![Captura de la app](captura.png)

### Tecnologías
- React 18 + Vite
- useState con lazy initializer
- useEffect para sincronizar con LocalStorage
- Express.js
- PostgreSQL

### Cómo correr el proyecto

**Frontend:**
```bash
cd fase1-viajes/frontend
npm install
npm run dev
```

**Backend:**
```bash
cd fase1-viajes/backend
npm install
npm run dev
```

### Estructura
```
fase1-viajes/
  frontend/    ← React + Vite
  backend/     ← Express + PostgreSQL
```
